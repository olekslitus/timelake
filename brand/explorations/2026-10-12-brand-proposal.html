Fast every day

        
Dashboards, trends and "what is the value now" read only the files and row groups they need. The latest value of every series comes from an index, not a scan.

Nothing to maintain

        
Compaction, deduplication, retention and snapshot cleanup run inside the writer. No Spark or Glue jobs to schedule, size, monitor or pay for.

        
1,728 commits · 0 external jobs
one optional command for a full rewrite

Pay for storage, not a database

        
No instance running all month. Your bill is bytes and requests on object storage, and Timelake keeps both low: compact files, sorted data, few requests per query.

        
228 MB vs 449 MB (Lance) for the same data

Open formatParquet files and open table metadata. DuckDB, Spark and PyIceberg read them today.

      
Any object storeS3, R2, GCS, Azure, MinIO or a disk. Read-only from any HTTPS host.

      
Apache 2.0The whole engine, the CLI and the clients. No closed core.

    

  


  
  

    

      
03 · Mark

      
Parallel lines that change together, inside a circle

      
Black, with sharp mitered corners. Each line is one series; they turn at the same moments, the way readings from one machine do. Shown at 104, 32 and 16 px, on paper and on ink.

    

    
    
Pulse, iterated

    

  






  






  
v0 · current
Five lines, vertical copies of one pulse. Recorded as the current mark.

  






  






  
v0.1
Truly parallel lines: the gap across the lines is the same on the slopes as on the flats. The outer lines become nested chevrons.

  






  






  
v0.2
Three bold parallel lines. The clearest at 16 and 32 px, so the favicon candidate even if v0 or v0.1 stays the main mark.

No catalog server

            
A commit is one conditional write of the next vN.metadata.json. Two writers can't both win, so there is no lock service and no database.

# Brand explorations

How the Timelake brand was chosen (October 2026). Kept so any decision can be revisited.

| File | What it is | Live page (owner only) |
|---|---|---|
| `2026-10-12-brand-proposal.html` | Messaging, the three promises, the instrument-panel (Oxide-inspired) look, Ice/Phosphor/Amber accents, the first six marks, and the "where Timelake runs" diagram. Final version (v3). | https://claude.ai/artifact/BpgDn5N6JxEuVwEdkJWdBC |
| `2026-10-13-pulse-variants.html` | The Pulse contact sheet: families A (copies), B (parallel), C and F (B2 refinements). Snapshot as reviewed. | https://claude.ai/artifact/J4E81wTdcJkFcYWFtHVv5M |
| `pulse-variants.mjs` | Generator for that sheet: `bun brand/explorations/pulse-variants.mjs out.html`. Later changes to `marks.mjs` (blend with dropped corners) can redraw a few C/F variants slightly differently than the snapshot. | |
| `../editor.template.html` | The interactive mark editor (build with `bun brand/build-editor.mjs`). Its presets include v1 and both alternates. | https://claude.ai/artifact/FHYmPYD2RtAiLJ9XuWUVrX (saved designs shelf included) |

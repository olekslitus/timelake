# Brand explorations

How the Timelake brand was chosen (October 2026). Kept so any decision can be revisited. Open the HTML files directly in a browser; they need only Google Fonts.

| File | What it is |
|---|---|
| `2026-10-12-brand-proposal.html` | Messaging, the three promises, the instrument-panel look, the Ice, Phosphor and Amber accents, the first six marks, and the "where Timelake runs" diagram. Final version (v3). |
| `2026-10-13-pulse-variants.html` | The Pulse contact sheet: families A (copies), B (parallel), C and F (B2 refinements). Snapshot as reviewed. |
| `pulse-variants.mjs` | Generator for that sheet: `bun brand/explorations/pulse-variants.mjs out.html`. Later changes to `marks.mjs` (blending when a corner drops out) can redraw a few C and F variants slightly differently from the snapshot. |

The mark itself was finished in the editor (`bun run brand:editor`); the designs saved there are in `../designs/`.
